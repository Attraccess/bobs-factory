Bob’s Factory

Downloads and installation

Choose an installation path for the way you run Bob. Each path is listed with its current availability; unpublished packages are not download links.

Verified command-line install

Available for macOS Apple Silicon/Intel and Linux ARM64/x64 with glibc. The bootstrap verifies the signed release before installing an immutable version under your user prefix. It does not install or start a service.

curl -fsSL https://jappyjan.github.io/bobs-factory/install.sh | sh

Channel, version, trust and recovery guide

A channel is installable only after a complete signed release is published. The bootstrap reports unavailable channels otherwise.

Native desktop app

Not available yet. The macOS DMG/Applications workflow and Linux desktop packages depend on the native app and real release assets. No terminal setup is claimed for this path.

Homebrew

No Bob’s Factory stable or nightly cask is published yet. The official cask command will be listed here after a real cask and release asset are available.

Linux packages

AppImage, DEB and AUR stable/nightly packages are not published yet. Current verified Linux downloads are the CLI archives installed by the bootstrap above.

Temporary npx trial

A Bob-owned npm launcher is not published yet. The package name and account ownership must be verified before publishing. npm/Node will be required for the launcher only; the native Factory runtime itself does not require Node, npm or Bun.

Prerequisites

Git and the coding agent you choose are prepared separately and remain host-owned. Some agents have their own runtime and login requirements. See the self-hosting guide.
